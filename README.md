# The Drinkers — uradna spletna stran 🍺

Profesionalna enostranska (one-page) spletna stran zasavske drink'n'roll skupine **The Drinkers** (Litija), posodobljena za poglavje **The Drinkers 2.0** in novi singl **„Ni še umru“ (2026)**.

## Struktura
- `index.html` — celotna vsebina (hero, novi singl, glasba/videi, zasedba, koncerti, galerija, zgodovina/timeline, pritisk, newsletter, booking/kontakt)
- `css/style.css` — slog: črno-zlata „pivska“ paleta, tipografija Oswald/Barlow, animacije, popolna odzivnost
- `js/main.js` — mobilni meni, scroll-spy, reveal animacije, števeci, lightbox galerija, obrazci
- `img/` — nove fotografije benda (2026) in koncertne slike (Garaža, Zagorje)

## Zagon
```bash
python3 -m http.server 8090   # nato odpri http://localhost:8090
```
Ali preprosto odpri `index.html` v brskalniku.
